## 1. Project Overview

This project demonstrates two fundamental operating system synchronization problems using semaphores and monitor-style synchronization:

1. Readers-Writers Problem using Semaphores
2. Readers-Writers Problem using Monitors
3. Dining Philosophers Problem using Semaphores
4. Dining Philosophers Problem using Monitors

The project uses Python threads to demonstrate how multiple threads coordinate access to shared resources. It records execution events and generates HTML visualizations that can be opened in a web browser.

The visualizations help illustrate how synchronization controls resource access and coordinates the activities of readers, writers, and philosophers. Since thread scheduling can vary, the sequence of events may differ between executions.

## 5. Synchronization Demonstrations

### A. Readers-Writers Problem using Semaphores

This demonstration shows how semaphores coordinate access to shared data. Multiple readers may access the resource according to the synchronization rules, while writing must be coordinated to prevent conflicting access.

### B. Readers-Writers Problem using Monitors

This demonstration uses monitor-style synchronization to coordinate readers and writers. It illustrates how shared-resource access can be controlled through synchronization mechanisms.

### C. Dining Philosophers Problem using Semaphores

This demonstration models philosophers competing for shared chopsticks. Each philosopher must acquire the required chopsticks before eating. Semaphores coordinate access to these shared resources.

### D. Dining Philosophers Problem using Monitors

This demonstration uses monitor-style synchronization to coordinate the philosophers' states and resource access. It illustrates how synchronization can manage competing requests to eat.
